# Meridian Health Network — Patient Intake Portal

## Overview
Build a modern patient intake portal for Meridian Health Network (fictitious), a regional healthcare system with 12 hospitals and 200+ clinics.

## Core Features

### Patient Self-Service Portal
- Online pre-registration with insurance verification
- Medical history questionnaire with smart branching
- Document upload (insurance cards, ID, referral letters)
- Appointment scheduling with provider availability

### Clinical Triage Agent
- AI-powered symptom assessment using structured clinical protocols
- Urgency classification (Emergency / Urgent / Routine)
- Automated routing to appropriate department
- Integration with EHR system via FHIR R4 APIs

### Lab Results RAG System
- Natural language queries against patient lab history
- Trend visualization for longitudinal results (A1C, lipid panels, etc.)
- Agentic retrieval using Azure AI Search
- HIPAA-compliant data handling with audit logging

### Provider Dashboard
- Real-time patient queue with triage scores
- Clinical decision support notifications
- Secure messaging with patients
- Shift handoff summaries generated by AI

## Non-Functional Requirements
- HIPAA compliance (PHI encryption at rest and in transit)
- SOC 2 Type II audit trail
- 99.9% uptime SLA
- Response time < 200ms for API calls
- Support 10,000 concurrent users during peak hours

## User Roles
- Patient (self-service registration and results access)
- Nurse (triage and intake workflows)
- Physician (clinical dashboard and decision support)
- Admin (system configuration and reporting)
- Compliance Officer (audit logs and access reviews)

## Technical Constraints
- Must integrate with Epic EHR via FHIR R4
- Azure-hosted (HIPAA BAA subscription required)
- Data residency: US-only regions
- Authentication: Azure AD B2C for patients, Azure AD for staff
