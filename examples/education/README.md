# Education Example — LearnTrack Platform

This example demonstrates the IgnitionStack pattern for a **student progress tracking platform**.

## Run It

```bash
ignition run examples/education/use-case.txt --project learntrack --tutorial
```

## What Gets Generated

- **Bicep infra** with FERPA/COPPA compliance tags
- **Adaptive assessment engine** with IRT scoring
- **Teacher intelligence agent** for natural language class analytics
- **Learning analytics RAG** powered by Azure AI Search
- **Accessible React dashboard** (WCAG 2.1 AA)

## Domain-Specific Agents

| Agent | Role |
|-------|------|
| Pedagogy Advisor | Ensures educational best practices and WCAG accessibility |
| Assessment Designer | Creates standards-aligned adaptive questions |
| Intervention Recommender | Suggests evidence-based interventions for learning gaps |
